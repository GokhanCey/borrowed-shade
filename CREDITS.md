# Credits

## Cover image

The two hands and the rabbit shadow on the cover are the "Bunny" plate from
Henry Bursill's *Hand Shadows to Be Thrown Upon the Wall* (1859), which is in the
public domain. Scan from [Project Gutenberg](https://www.gutenberg.org/ebooks/12962).

## Music and sound

All music and sound effects are generated in code while the game runs. There are
no audio files and no samples in this project.

## Art

The paper scenery, puppets and shadow outlines are drawn in code for this project.

## Libraries

- Immersive Web SDK (`@iwsdk/core`), Meta
- three.js
- `@pmndrs/uikit`
- Vite and TypeScript

Each library is used under its own license. See `package.json` for versions.
